# Library-Management-System
Java desktop application for managing library operations using Java Swing and SQLite.

## Features

- User Login
- User Registration
- Book Management
- Member Management
- Borrow and Return Books
- Book Reservations
- Fine Management
- Reports
- Search Books
- SQLite Database Integration

## Technologies

- Java
- Java Swing
- SQLite
- JDBC

## How to Run

1. Open the project in NetBeans or another Java IDE.
2. Ensure the SQLite JDBC library is included.
3. Run the project.

## Database

The application uses an SQLite database to store:

- Books
- Members
- Loans
- Reservations
- Fines
